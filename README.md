# Nirnoy Fintech Portfolio Website

A static HTML/CSS/JavaScript portfolio website created from the CV of Md. Al Muhayminul (Nirnoy) Islam.

## Files
- index.html
- style.css
- script.js

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `nirnoy-portfolio`.
2. Upload all three files to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide your live website URL.

## Customize
- Change content in `index.html`
- Change design/colors in `style.css`
- Add LinkedIn and GitHub links when available
